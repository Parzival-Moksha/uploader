# Keys

## Moving and the camera

| Key | What it does |
|---|---|
| W A S D, or the arrows | Walk |
| Shift (held) | Run |
| Space (held) | Walk slowly |
| Left click on the world | The mouse turns the view; Esc gives the mouse back |
| Mouse wheel | Camera nearer or farther |
| C | Camera: around a point, flying free, or behind you |
| Q / E | Up / down, while flying free |

## Agents

| Key | What it does |
|---|---|
| E | Open the nearest agent's panel (or the selected one's); again to close |
| F | The agent's full screen; again to close |
| T | Next to an agent: open it with the microphone on; with one open, microphone on and off |
| Ctrl + Space | Dictate into the open agent's box |
| Enter | Send what is in the box |
| N | Jump to the next agent that needs you (a question, a permission, an error) |
| Esc | Close the panel or the full screen |
| Delete | Dismiss the open or selected agent (asks first) |
| Click an agent | Select it; click again to open it |
| Right click on the ground | With an agent selected: it walks there |
| E in the circle on the plaza | Summon an agent |

## Menus

| Key | What it does |
|---|---|
| M | The main menu |
| Esc | Close the topmost thing, one per press; with nothing open, the main menu |
| B | The spell book |
| F8 | Rest (away); any key wakes |

The four buttons at the top left: **Menu**, **World**, **Spells**, **Agents**.

## Building

| Key | What it does |
|---|---|
| Left click an object | Select it; double click: select it and open its move / turn / scale fields |
| R / T / Y | Handles to move / turn / scale the selected object |
| Delete | Delete the selected object |
| Ctrl + Z, Ctrl + Y | Undo, redo |
| Ctrl + C, Ctrl + V | Copy, paste (then click where it goes) |
| While placing | Left click places; right click or Esc cancels |
| Painting the ground | Left click paints, right click erases |
| PgDn / PgUp | Next / previous picture placed in the world |
| Left / right arrow | Next / previous picture in an agent's picture viewer |
| Ctrl + Shift + P | A panorama screenshot |

## Spells (play mode)

Pick a spell in the spell book (B), then left click (with the mouse turning the view) to cast. Hold **M** where the health and mana bar shows to refill mana.
